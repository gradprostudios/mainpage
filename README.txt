GRAD PRO STUDIOS — Graduation Photography Landing Page

Files:
- index.html
- style.css
- script.js
- assets/GPS.png (existing Grad Pro Studios logo asset)
- frames/ (place your existing graduation sample images here)

To use the seven gallery photos, copy the existing project assets into frames/ with these exact filenames (keep your originals unchanged if you prefer to edit the src paths in index.html):
  sample1.png
  sample2.png
  sample3.png
  sample4.png
  sample5.png
  sample6.png
  sample7.png

If your sample files use .jpg, .jpeg, or .webp extensions, update the seven img src values in index.html to match those exact extensions. The source images were not present in the available project files at build time, so they have not been fabricated or replaced.

Run locally by opening index.html in a browser, or deploy the folder to any static web host. No build step or dependencies required. The font links need internet access; local system fallbacks are included.

Existing verified social link used: https://www.facebook.com/gradprostudios
